# Scarborough Supercentre and doorway navigation

Walmart is available under Explore → Scarborough → Walmart Supercentre, next to the Town Centre on the compressed map. Walk to its facade and use the entrance. The reference is Walmart store 3635 at 300 Borough Drive: https://www.walmart.ca/en/store/3635. The game uses the existing OSM Town Centre anchor for this mall tenant, with an adjacent compressed cell so doors remain independently selectable. This is an original stylised layout, not a surveyed store plan. Store purchases use game money.

The 48 × 40 interior has 12 stocked sections covering produce, pantry/bakery, household goods, clothing, electronics and toys/home; four staffed tills; customer service, seating and a bathroom. The camera follows the player across the larger floor. Shoppers browse aisle bays, carry bags and yield to the player. Counts are capped at 18 desktop / 8 mobile, lower in reduced graphics mode. Clothing racks, packaged stock and electronics use the instanced furniture kit. The `format: 'supercentre'` furnishing option retains palette overrides, additions and omissions for reuse.

The navigation failure was an isolated approach at the positive-side pavement (`cell + 5`), which the public route grid does not use. Routing from elsewhere to those doors recursively tried to reach the same approach until the stack overflowed. House approaches now use their central corridor to the connected south sidewalk; shop doors face the connected east sidewalk. Benches sit beside that corridor. Invalid approach definitions are explicitly rejected instead of recursing. Street-layout migration recovers old positions and relocates existing rest poses to the correct bench.

Tests cover complete outbound/return routes for every generated address, rendered movement along every final entrance segment, every store interaction/exit path, shopper bay clearance, and TTC → door → enter → browse → pay → save → exit. Rendered visual and mobile performance review remains pending because the available browser cannot create a WebGL context.
